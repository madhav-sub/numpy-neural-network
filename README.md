# Neural Networks from Scratch — NumPy

A configurable implementation of multilayer perceptrons (MLPs) using NumPy, developed to explore the mathematical foundations and implementation details of neural-network learning.

The project implements forward propagation, backpropagation, and gradient-based optimization without relying on high-level deep-learning frameworks.

It supports multiple network layers and can be configured for different learning tasks, including:

- Binary classification with sigmoid-based outputs
- Multiclass classification
- Regression

The emphasis is on understanding and implementing neural-network computations directly, rather than delegating training and differentiation to an existing framework.
